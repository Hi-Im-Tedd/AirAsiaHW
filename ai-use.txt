The AI tool used for this assignment is the built in copilot tool within GitHub Codespace

AI Prompts used

1) erate HTML code for form that can be used to collect login information. Include username and password fields and a login button. The login button must direct the user to card-list.php.
2) erate code that lists information about a giftcard. The information will include the Gift Card.jpg image, text for card name and points required.
3) erate code that will use description list to provide details about a giftcard. The decription must include the Gift Card.jpg image, card name, card description, card type, card value in dollars and the points required. Place card image at the top of the page in the center. Center the card name below the image. Below card name place the card description. Under the card description place the remaining information.
